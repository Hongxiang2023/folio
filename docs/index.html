Start here

Download the source. Run the app.

The current preview runs from source on macOS, Windows, and Linux. You’ll install Node.js once, then launch Folio from the downloaded project folder.

No ready-to-install app download yet. The ZIP below contains source code, not a .dmg or .exe installer. The demo illustrates Folio; it does not install the app.
1

Install Node.js

Install Node.js LTS, version 22.13 or newer. It includes npm, which installs Folio’s dependencies.

Get Node.js ↗
2

Download and unzip

Download the project ZIP and extract it. Open the folio-main folder; it should contain package.json.

Download source ZIP ↓
3

Launch Folio

Open Terminal or PowerShell in that folder and run the two commands below. Internet is needed for the first setup.

Step-by-step installation →

First launch

npm ci
npm run desktop

Wait for setup to finish. Folio opens in its own desktop window. Keep the terminal open while using it.

Next time

npm run desktop

Run this inside the same project folder. Your papers stay in Folio’s separate local library folder. Quit any running Folio instance before launching another.

One workflow, from source to submission.

Collect & organize

Import PDFs or references. Save from Chrome or Edge. Keep collections, notes, tags, stars, and reading status together.

Read & understand

Explore article text and figures beside the original PDF. Highlight passages, zoom figures, and optionally ask questions using your AI connection.

Cite & revise

Use PMID, DOI, arXiv, or local paper markers. Export Word, make revisions, and re-upload to refresh your bibliography.
