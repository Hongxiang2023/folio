Download Refhaven for Mac ↓

  1. Download the DMG

    For an Apple silicon Mac running macOS 13 or newer.

  2. Drag Refhaven into Applications

    Open the DMG. Quit an older Refhaven before replacing it.

  3. Open Refhaven

    Launch from Applications. Eject the disk image afterward.

A note about this preview

Refhaven is not yet Developer ID-signed or Apple-notarized. macOS may block first launch. If you trust this download, follow the first-launch instructions. Keep normal macOS security protections enabled.

Intel Mac, Windows, or Linux? Run from source (Node.js required). Installers for those platforms are not provided yet.

Your library. Your choice.

No Refhaven account, subscription, or analytics. Core features work locally. Cloud folders use your provider’s desktop app; optional AI uses your own connection and is enabled per paper. Provider fees and account limits may apply.
